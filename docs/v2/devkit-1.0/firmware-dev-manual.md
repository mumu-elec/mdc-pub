# MDC 电机驱动板 · 固件二次开发手册

> **版本：** v1.0（2026-09-23）
> **适用对象：** 拿到 Motor Driver Controller 四路电机驱动板（STM32F401RCT6 + TB6612 ×2），
> 希望抛开出厂固件、自行开发固件的开发者。
> **内容边界：** 本手册只包含**引脚分配与外设配置**。文中"推荐配置"即出厂固件（v1.2.0）所采用
> 的配置，可直接沿用；你完全可以按自己的需求修改，但请遵守"板级约束"栏中的提示。
> **配套资源：** [固件二次开发库 firmware-dev-kit](firmware-dev-kit/)（可直接编译的工程骨架，
> 本手册所有配置在该库中均有对应代码）。硬件接口、接线与出厂固件的使用请见《技术手册》。

---

## 1. 硬件资源概览

| 资源 | 型号 / 规格 | 说明 |
|------|------------|------|
| MCU | STM32F401RCT6 | LQFP64，Cortex-M4F，最高 84MHz，256KB Flash，64KB RAM |
| 电机驱动 | TB6612FNG ×2 | 双通道 brushed 驱动，共 4 路（连接器 A/B/C/D） |
| TB6612 STBY | 硬件上拉至 3.3V | **无需软件控制**，上电即处于使能状态 |
| 板载 EEPROM | AT24C02（I2C） | 256 字节，7 位地址 0x50，页大小 8 字节 |
| USB 串口 | CH340N → Type-C | 连接 USART6；RTS# 与 MCU NRST 相连（支持上位机自动复位进 Bootloader） |
| 控制输入调理 | 74LVC1G386 三输入异或门 | CN2 无极性输入 + 极性软件可控，详见 §5.3 |
| 状态 LED | 0603 红色 | PA4，**低电平点亮** |
| 按键 | FUN（PC0）、RST | FUN 外部 10KΩ 上拉，按下为下降沿 |
| 晶振 | 8MHz HSE | 失效时软件可降级为 HSI（见 §4） |
| 编码器供电 | +3.3V | 电机连接器第 5 脚输出 |

## 2. 板级接口

| 接口 | 规格 | 用途 |
|------|------|------|
| A / B / C / D | 6-Pin XH 2.5mm | 电机 + 编码器（1=MOTOR_OUT2，2=GND，3=ENC_A，4=ENC_B，5=+3.3V，6=MOTOR_OUT1） |
| CN2 | 2-Pin 1.25mm | 控制信号输入（SBUS / UART，无极性，经异或门） |
| USB | Type-C | 调试串口 / 上位机连接（经 CH340N → USART6） |
| DC IN | DC-005 2.1mm | 电机电源输入（内正外负） |
| SWD | 4-Pin 1.27mm | 3V3 / SWDIO / SWCLK / GND |

## 3. 引脚分配（推荐配置）

### 3.1 PWM 输出 → TB6612（TIM1）

| 电机连接器 | IN1 | IN2 | PWM 引脚 | 定时器通道 |
|-----------|-----|-----|----------|-----------|
| A | PC12 | PC11 | PA9 | TIM1_CH2 |
| B | PA12 | PC9 | PA8 | TIM1_CH1 |
| C | PA15 | PC10 | PA10 | TIM1_CH3 |
| D | PB4 | PD2 | PA11 | TIM1_CH4 |

> **板级约束：** TIM1 是板上唯一 4 个通道全部引出到 TB6612 的定时器；4 路 PWM 与
> 方向脚的对应关系由 PCB 布线决定，**软件无法互换**。TB6612 逻辑：
> IN1/IN2 = 00 滑行、01 正转、10 反转、11 短接刹车（高电平有效）。

### 3.2 编码器输入（定时器编码器模式，硬件 4 倍频）

| 电机连接器 | 定时器 | CH1（A 相） | CH2（B 相） | 计数器宽度 |
|-----------|--------|------------|------------|-----------|
| A | TIM3 | PA6 | PA7 | 16 位（0~65535） |
| B | TIM5 | PA0 | PA1 | 32 位 |
| C | TIM2 | PA5 | PB3 | 32 位 |
| D | TIM4 | PB6 | PB7 | 16 位 |

> **板级约束：** 编码器接口与电机连接器一一对应，由 PCB 布线决定。16 位定时器
> 高速单向旋转约每几千计数就溢出回绕，需自行做圈数累计（32 位则几乎无此顾虑）。

### 3.3 通信与特殊功能引脚

| 功能 | 引脚 | 方向 | 推荐配置 | 说明 |
|------|------|------|----------|------|
| 控制输入 | PA3（USART2_RX） | 输入 | AF7，无上下拉 | SBUS / UART 共用输入口，经板上异或门调理 |
| 极性控制 | PC13 | 输出 | 推挽，初始低 | 异或门极性：**0 = 直通，1 = 反相** |
| USB 调试串口 | PC6（USART6_TX）/ PC7（USART6_RX） | 双向 | AF8；PC7 建议**上拉**防悬空噪声 | 经 CH340N 接 Type-C，连接上位机 |
| EEPROM | PB8（I2C1_SCL）/ PB9（I2C1_SDA） | 双向 | AF4 开漏 | 板上已有 4.7KΩ 外部上拉，无需内部上拉 |
| 状态 LED | PA4 | 输出 | 推挽，初始低 | 低电平点亮 |
| FUN 按键 | PC0 | 输入 | EXTI0 下降沿，无内部上下拉 | 外部 10KΩ 上拉，按下接地 |
| 预留 | PC5 | 输出 | 推挽，初始低 | PCB 网络仅引至 MCU，功能预留 |
| 晶振 | PH0 / PH1 | — | HSE 外部 8MHz | — |

### 3.4 防浮空与不可用引脚

| 引脚 | 推荐配置 | 原因 |
|------|----------|------|
| PA2 | 输入下拉（内部） | 早期硬件曾用作极性控制，现由 PC13 接管；下拉防旧板浮空干扰异或门。未来启用 USART2_TX 时由 AF 配置自然覆盖 |
| PA11 / PA12 | 已被 TIM1_CH4 / 电机方向占用 | 这两个脚与 USB 数据脚（DM/DP）复用——板载 Type-C 因此**仅作供电与串口**，不可再做 USB 设备 |

## 4. 时钟系统（推荐配置）

```
HSE 8MHz ──/M=8──► PLL(×N=336, /P=4) ──► SYSCLK 84MHz ──► AHB /1 = 84MHz
                                                          ├─ APB1 /2 = 42MHz（APB1 定时器 ×2 = 84MHz）
                                                          └─ APB2 /1 = 84MHz（APB2 定时器 = 84MHz）
```

| 配置项 | 推荐值 |
|--------|--------|
| 电源调压器 | Scale 2（84MHz 档位） |
| PLL | M=8，N=336，P=4，Q=7（Q 输出 48MHz 档，本板未用 USB） |
| Flash 等待周期 | 2（FLASH_LATENCY_2） |
| SysTick | 1ms（HAL 默认） |
| HSE 失效降级 | 切换 PLL 时钟源至 HSI：M=16，N=336，P=4 → 同样 84MHz 继续运行 |

> **注意：** 从 Bootloader 跳转或热复位进入 APP 时，SYSCLK 可能已在 PLL 上。
> 重新配置时钟前需先把 SYSCLK 切回 HSI，否则 `HAL_RCC_OscConfig` 会返回错误。

## 5. 外设推荐配置

### 5.1 TIM1 — 四路电机 PWM

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 预分频 PSC | 3 | 84MHz / (3+1) = 21MHz 计数时钟 |
| 自动重装 ARR | 1000 | PWM 频率 = 21MHz / 1000 = **21kHz**（超声频段，无啸叫） |
| 计数模式 | 向上 | — |
| 输出比较 | PWM1 模式，高有效，空闲低 | 占空比 = CCR / (ARR+1)，即 CCR 0~1000 对应 0~100% |
| 死区 / 刹车 | 不使用 | TB6612 为单线 PWM + 双电平方向控制，无需互补输出与死区 |

> **调整提示：** 改 PSC/ARR 会同时改变 PWM 频率与占空比分辨率。建议保持在 16~32kHz
> 超声频段；TB6612 开关频率上限远高于此，但过低会产生可闻噪声，过高会加大开关损耗。

### 5.2 TIM2 / TIM3 / TIM4 / TIM5 — 编码器接口

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 模式 | Encoder Mode TI12 | 双相计数（4 倍频）：每编码器线计数 4 次 |
| 输入极性 | 双通道上升沿 | 方向修正靠交换 A/B 相或软件取反 |
| 输入滤波 | IC filter = 4 | 抑制电机干扰毛刺；过大导致高速丢步 |
| 预分频 | 不分频 | — |
| ARR | 32 位定时器取 0xFFFFFFFF；16 位取 0xFFFF | 16 位定时器需软件处理回绕 |

> **使用提示：** 初始化后调用 `HAL_TIM_Encoder_Start(&htimX, TIM_CHANNEL_ALL)`，
> 之后直接读 `TIMx->CNT`。转速 =（计数增量 / 4 / 编码器线数）/ 时间。

### 5.3 USART2 — 控制信号输入口（PA3）

CN2 输入经板上 74LVC1G386 异或门调理后接入 PA3。异或门第三输入接 PC13，
因此**信号极性可软件控制**：

| PC13 电平 | 效果 |
|-----------|------|
| 低（0） | 直通：普通 UART / TTL 信号原样进入 PA3 |
| 高（1） | 反相：SBUS（反相逻辑，100000bps 8E2）等反相信号被校正为标准 UART 逻辑 |

| 参数 | 推荐值 |
|------|--------|
| 模式 | RX only（板上仅 PA3 接入信号） |
| 初始波特率 | 115200，8N1（普通 UART） |
| SBUS 场景 | 100000bps，8E2（偶校验，2 停止位），PC13 = 1 |
| 接收方式建议 | DMA 循环接收：**DMA1 Stream5 / Channel4** |

> **板级约束：** CN2 两个引脚经 10KΩ 下拉电阻接入异或门的两个信号输入，任意方向插入
> 均可工作（无极性）；未插入时 PA3 输入为固定低电平。详见 §3.3 的 PC13 说明。

### 5.4 USART6 — USB 调试串口（PC6/PC7）

| 参数 | 推荐值 |
|------|--------|
| 波特率 | 2000000，8N1，双向 |
| GPIO | AF8 推挽；PC7（RX）内部上拉，防 CH340 未连接时悬空噪声 |
| DMA 建议 | RX = **DMA2 Stream2 / Channel5**，TX = **DMA2 Stream6 / Channel5** |
| 中断 | 使能 USART6 中断（推荐抢占优先级 5） |
| 稳健性 | 若产品含 Bootloader，在 `HAL_UART_MspInit` 中对 USART6 做一次外设强制复位，清除跳转残留状态（否则 TXE 可能不置位导致发送超时） |

### 5.5 I2C1 — 板载 EEPROM（PB8/PB9）

| 参数 | 推荐值 |
|------|--------|
| 速率 | 100kHz（标准模式） |
| 寻址 | 7 位，本机地址 0 |
| GPIO | AF4 开漏，无内部上拉（板上 4.7KΩ） |
| 目标器件 | AT24C02 @ 0x50，页大小 8 字节，页写周期约 5ms |

> **板级约束：** AT24C02 上电稳压建立（tPU）晚于 MCU 就绪，首次访问可能失败——
> 建议初始化后带重试或延时。写入后需等待写周期完成（ACK 轮询）再进行下一次写。

### 5.6 GPIO 输出（TB6612 方向脚等）

所有方向/控制脚为推挽输出、低速档、**初始低电平**（上电即电机滑行、LED 灭、直通极性）：

```
PA4  PA12 PA15            （LED、电机 B/C 方向）
PC5  PC9  PC10 PC11 PC12 PC13（预留、电机 A/B/C 方向、极性控制）
PD2  PB4                  （电机 D 方向）
```

### 5.7 NVIC / 中断

| 配置项 | 推荐值 |
|--------|--------|
| 优先级分组 | Group 4（4 位抢占，无子优先级） |
| EXTI0（FUN 按键）、USART2、USART6 | 抢占优先级 5 |
| SysTick | 优先级 15（HAL 默认最低） |

### 5.8 IWDG — 独立看门狗（推荐启用）

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 预分频 | 64 | LSI 32kHz / 64 = 500Hz |
| 重装值 | 500 | 超时约 1 秒 |

> **注意：** 调试挂起时建议冻结 IWDG（`__HAL_DBGMCU_FREEZE_IWDG`）；主循环里若有
> 长阻塞操作（如 EEPROM 页写），确认喂狗周期留有余量。

## 6. Flash 布局与 Bootloader 兼容

出厂板 Flash 前 16KB 为 Bootloader（支持上位机一键升级固件）。自行开发固件时：

| 区域 | 地址范围 | 大小 |
|------|----------|------|
| Bootloader | 0x08000000 ~ 0x08003FFF | 16KB |
| 应用（APP） | **0x08004000** ~ 0x0803FFFF | 240KB |

保留 Bootloader 兼容只需两处配置（二次开发库已按此配置）：

1. **链接脚本**：FLASH `ORIGIN = 0x08004000, LENGTH = 240K`；
2. **向量表重定位**：`main()` 最开头（使能中断前）执行
   `SCB->VTOR = 0x08004000;`（配 `__DSB/__ISB` 屏障）。

兼容 Bootloader 的好处：可用出厂上位机的"固件升级"功能直接刷自己编译的 `.bin`
（FUN 键按住上电或上位机自动复位均可进入 Bootloader）。

> **不需要 Bootloader？** 链接脚本改回 `ORIGIN = 0x08000000, LENGTH = 256K`，
> 删除 VTOR 重定位语句。此后只能经 SWD 烧录。

## 7. 二次开发库使用

配套的 [firmware-dev-kit](firmware-dev-kit/) 是按本手册推荐配置搭好的可编译工程：

- `motor_driver_ctrl.ioc`：CubeMX（6.14+）工程文件，图形化改配置后重新生成；
  `USER CODE` 区块内的手写代码会被保留；
- `make -j8` 或 `build.bat` 一键编译，产物 `build/mdc_devkit.bin/.hex/.elf`；
- demo：LED 闪烁 + 四路编码器计数经 USART6 打印 + 电机开环转动示例（默认注释）；
- 编译、烧录、改配置的完整说明见库内 `README.md`。

## 8. 已知约束速查

| 约束 | 影响 |
|------|------|
| PA11/PA12 被 PWM/方向占用 | USB 设备功能不可用，Type-C 仅供电 + 串口 |
| TIM1 为唯一 4 通道全引出定时器 | 4 路 PWM 无法换用其他定时器 |
| TIM3/TIM4 计数器 16 位 | 高速编码器需软件处理回绕与圈数 |
| TB6612 STBY 硬接 3.3V | 无法软件断开电机；安全停机请用 PWM 占空比 0 + 方向 00（滑行） |
| 编码器电源固定 3.3V | 5V 供电编码器需外部供电并注意电平兼容 |
| PA3 仅输入 | 需要向控制源回发数据时，请使用 USART6（USB 侧） |
| CN2 无极性 + 软件极性 | PC13 电平按信号类型选择（UART=直通，SBUS=反相） |
