# Arduino UNO 例程 — SoftwareSerial 连接 RC 口（文本指令 + 二进制控制帧）

基于 **Arduino UNO（ATmega328P，16MHz）** 的 Motor Driver Controller 上位机例程：用 SoftwareSerial 连接控制板 **RC 接口（USART2）**，支持文本指令终端交互与 0x31 实时控制帧发送。

## 功能

- **USB 串口交互终端**：在串口监视器输入任意文本指令（如 `/version`、`/status`、`/mode 1 speed`），自动转发到 RC 口并回显控制板返回内容。
- **数字快捷键菜单**：

| 按键 | 动作 |
|:---:|------|
| `1` | 发 `/version` |
| `2` | 发 `/status` |
| `3` | 开环正转 PWM=400（ch1，持续发送） |
| `4` | 开环反转 PWM=-400（ch1，持续发送） |
| `5` | 停止（ch1~4，结束持续发送） |
| `6` | 速度模式目标 100RPM（先发 `/mode 1 speed` 再发 0x31 帧） |
| `7` | 发 `/save` |

- **二进制帧封装函数**（严格按规范 §3 实现）：`crc8()`、`send_frame(cmd, data, len)`、`send_motor_ctrl(int32_t targets[4])`（0x31，int32 小端手动移位拼装，不依赖 union 对齐）。
- 快捷键 3/4/6 开启后按 **50ms 周期连续发送** 0x31 控制帧（满足规范 §3.3「实时控制以 30/50/100ms 间隔连续发送」），避免单帧被 `/timeout` 超时归零。

## 硬件接线（引脚表）

| Arduino UNO | 控制板（RC 接口 / USART2） | 说明 |
|-------------|---------------------------|------|
| Pin 11（TX） | RC 信号（RC RX） | 单片机发 → 控制板收 |
| Pin 10（RX） | RC 信号（RC TX） | 控制板发 → 单片机收 |
| GND | GND | **必须共地** |

文字图：

```
Arduino UNO                     Motor Driver Controller
┌──────────┐                    ┌──────────────────┐
│ Pin11 TX ├───────────────────►│ RC(RX)  USART2    │
│ Pin10 RX │◄───────────────────┤ RC(TX)            │
│ GND      ├───────────────────►│ GND               │
└──────────┘                    └──────────────────┘
```

> 注意：接线接的是控制板的 **RC 接口（USART2）**，不是 USB 口。TX/RX 交叉连接，GND 共地。

## 控制板预配置

控制板 USART2 默认为遥控模式（SBUS/ELRS），必须先切到 UART 模式。用 USB 串口工具（波特率 **2000000-8N1**）连接控制板后执行：

```
/uart2 115200 0 uart
```

- 波特率 115200，极性正常，模式 uart（立即生效并应用）。
- 默认控制优先级为 **USART2 优先**（`/priority 0`），因此本例程从 RC 口发出的 0x31 控制帧天然生效；若 USB 上位机同时发控制帧，需注意仲裁（规范 §1、§3.4）。
- 若想关闭超时归零保护，可执行 `/timeout 0`（可选）。

## 开发环境与编译

1. 安装 [Arduino IDE](https://www.arduino.cc/en/software)（任意近期版本）。
2. 板型选择：**工具 → 开发板 → Arduino AVR Boards → Arduino Uno**。
3. 端口选择：**工具 → 端口 → 选择 UNO 对应的 COM 口**。
4. 打开 `motor_driver_uno.ino`，点击「上传」（本例程不依赖任何第三方库，仅用内置 SoftwareSerial）。
5. 打开**串口监视器**，波特率选 **115200**，换行符选「换行」（Newline），即可交互。

## 运行与操作说明

- 上电后串口监视器打印快捷键菜单。
- 直接输入文本指令（如 `/version`）回车 → 转发到 RC 口，控制板返回内容原样打印。
- 按数字键 `1`~`7` 触发对应快捷键动作。
- 菜单 3/4/6 会持续发送控制帧，按 `5` 停止；需要改变目标值时重新按对应数字即可。

## 代码结构

| 函数 | 说明 |
|------|------|
| `crc8()` | CRC8（多项式 0x07、初值 0），计算范围 = CMD+LEN+DATA，按规范 §3.1 移植 |
| `send_frame(cmd, data, len)` | 组帧 `[0xAA][CMD][LEN][DATA][CRC8]` 并发送 |
| `put_i32_le()` | int32 小端手动拼装（避免 union 对齐问题） |
| `send_motor_ctrl(targets[4])` | 发送 0x31 四通道控制帧（16B DATA） |
| `send_text(cmd)` | 发送文本指令（自动补 `\n` 结尾） |
| `runMenu(n)` | 数字快捷键分发 |
| `handleLine(line)` | USB 行输入处理：单数字=菜单，否则文本指令 |
| `loop()` | 收行转发 + RC 回显打印 + 50ms 周期连续控制 |

## 用到的协议命令

| 类型 | 命令/帧 | 说明 |
|------|---------|------|
| 文本指令 | `/version` | 版本查询 |
| 文本指令 | `/status` | 全部配置参数 |
| 文本指令 | `/mode 1 speed` | ch1 切速度闭环 |
| 文本指令 | `/save` | 配置写入 EEPROM |
| 二进制帧 | `0x31 MOTOR_CTRL` | `[m1~m4: 4×int32 LE]` 四通道控制 |
| 二进制帧 | 帧头 `0xAA` + CRC8 | 多项式 0x07、初值 0，范围 CMD+LEN+DATA |

## 常见问题

| 现象 | 原因 / 处理 |
|------|------------|
| RC 口无响应 | 控制板未执行 `/uart2 115200 0 uart`；或 TX/RX 接反、未共地 |
| 串口监视器出现乱码 | 监视器波特率不是 115200；或换行符设置不对（需「换行」） |
| 电机不动 / 转一下即停 | 控制帧被 `/timeout` 超时归零：例程已 50ms 连续发送；确认菜单 3/4/6 处于持续发送状态；或发 `/timeout 0` 关闭保护 |
| **SoftwareSerial 在 115200 下偶发乱码** | ATmega328P 16MHz 下 SoftwareSerial 靠位翻转软件模拟，115200 已接近其速率上限（中断关闭期间会丢字节）。若回显乱码：① 把例程 `rcSerial.begin(115200)` 改为 `9600`，同时在控制板执行 `/uart2 9600 0 uart`；② 或改用硬件 UART（D0/D1）接 RC 口 |
| 控制帧时灵时不灵 | 控制板处于协议自动识别（/detect）期间会拒绝控制帧，稍等识别完成即可 |
| USB 端口识别不到 | 确认 CH340 驱动已装；控制板 USB 口波特率固定 **2000000-8N1**，与 Arduino 的 115200 是两回事 |
