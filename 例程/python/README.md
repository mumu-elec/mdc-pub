# Python 例程

> 使用 `mdc_lib/python`（完整版）+ `mdc_lite`（极简版）。所有例程按**功能级别**分为三类。

## 目录导航

| 类别 | 目录 | 场景 |
|------|------|------|
| **完整** | [完整/](完整/) | 协议全功能示例：连通 / 文本指令 / 二进制协议 / 实时控制 / 状态监控 / 配置读写（01~06） |
| **极简控制** | [极简控制/](极简控制/) | 只用 `mdc_lite` 发送 0x31 控制帧（只管调用，不看回包） |
| **控制+回调** | [控制+回调/](控制+回调/) | 用 `mdc_lite_ctrl` 发控制帧 + 订阅 `0xF0` 并用速度回调打印四通道 rpm |

## 依赖与 mdc_lite / mdc_lib

- 每个例程目录内的库文件已内置（`mdc_lib.py` [+ `mdc_lite.py`] [+ `mdc_lite_ctrl.py`]），开箱即用。
- `mdc_lib`（完整版）与 `mdc_lite`（极简版）的源码与 API 见 [`../../mdc_lib/`](../../mdc_lib/README.md)，
  极简版规范见 [`../../mdc_lib/LITE.md`](../../mdc_lib/LITE.md)。
- 升级库版本：用 `../../mdc_lib/python/` 下同名文件覆盖各例程内的库文件。

## 快速开始

1. 安装依赖（极简控制 / 控制+回调 需 `pyserial`）：
   ```bash
   pip install -r 极简控制/requirements.txt
   ```
2. 连上设备（USB 虚拟串口 **2000000-8N1**），先试 `极简控制` 跑通发送，再看 `控制+回调` 回读转速。
3. 经 USB 做实时控制前，下位机需已设置 `/priority 1`（USB 主控）。
