# Motor Driver Controller — 通信协议规范

> **适用对象：** 本目录下所有上位机例程（Python / C++ / ROS / MicroPython / 单片机）。
> **协议版本：** 布局 v2.x（config_t = 248B），27 条文本指令，19 条二进制命令。
> **配套固件：** firmware v1.2.0+（SW_MAJOR=2，协议版本 D=2）。
> **上位机版本规则：** 上位机版本 vD.F 的 D（协议版本）必须与固件 SW_MAJOR（D）一致，否则协议不兼容。

---

## 1. 连接方式

| 端口 | 位置 | 默认参数 | 承载内容 |
|------|------|---------|---------|
| USART6（USB） | Type-C（CH340N 虚拟串口） | **2000000-8N1** | 文本指令 + 二进制帧 + Bootloader 刷写 |
| USART2（RC 接口） | 2-Pin 1.5mm 插座 | 由配置决定（SBUS/ELRS/UART） | 文本指令 + 二进制帧 + SBUS/ELRS 遥控帧 |

**关键点：**

- 电脑上位机一律通过 **USB 虚拟串口（2000000-8N1）** 通信，波特率不可更改。
- 单片机 / MicroPython 板接入 RC 接口时，需先把 USART2 配置为 UART 模式：
  ```
  /uart2 115200 0 uart      # 波特率 115200，极性正常，模式 uart
  ```
  之后 USART2 即可收发文本指令与二进制帧（需共地）。
- **控制优先级（重要）：** `/priority 0`（默认）= USART2 优先（遥控器主控）；`/priority 1` = USB 优先（上位机主控）。
  - 配置类指令（/mode、/speedctrl 等）不受优先级限制，随时可发。
  - **控制帧（0x30 MOTOR_RAW / 0x31 MOTOR_CTRL）受仲裁**：非优先端口只有在优先端口失联超过心跳窗口（`/timeout` 值，最小 100ms）后才可接管；优先端口恢复发帧立即夺回。
  - 因此：**上位机（USB）做实时控制时，请先执行 `/priority 1`**；遥控器/USART2 为主控时保持 `/priority 0`。
- 命令超时保护：`/timeout <ms>`，超过设定时间未收到控制指令，所有电机输出归零；0 = 关闭保护。
- 协议自动识别（SBUS/ELRS/UART）：长按 FUN 键 1 秒，或发送 `/detect` 指令。

## 2. 文本指令集（27 条）

### 2.1 通用规则

- **带参数 = 写入**（仅修改 RAM，即时生效）；**不带参数 = 读取**（查询当前值）。
- 通道编号 `ch`：1~4 对应 Motor A~D。
- 写入后需执行 `/save` 才能持久化到 EEPROM（`/uart2` 除外：设置后立即生效并应用）。
- 成功写入返回 `OK (RAM only)`。
- 可选参数按顺序省略，省略的尾部参数保持当前值不修改。

### 2.2 系统指令（8 条）

| 指令 | 说明 |
|------|------|
| `/help` | 打印所有可用命令 |
| `/version` | 显示硬件/软件版本 |
| `/status` | 打印全部配置参数 |
| `/check` | 显示实时状态（编码器/RPM/输出/运行时间） |
| `/detect` | 重新检测 USART2 工作模式/波特率 |
| `/save` | 当前 RAM 配置写入 EEPROM |
| `/load` | 从 EEPROM 重新加载配置到 RAM |
| `/reset` | 恢复出厂默认值 |

### 2.3 控制器指令（7 条）

| 指令 | 语法 | 说明 |
|------|------|------|
| `/speedctrl` | `/speedctrl <ch> [kp ki kd [ilim [olim [period [ptype]]]]]` | 速度环 PID。kp/ki/kd 必须同设；ilim=积分限幅；olim=输出限幅(PWM 0~1000)；period=周期(ms)；ptype=0 位置式 / 1 增量式（增量式忽略 ilim，但设置靠后参数时需占位） |
| `/posctrl` | `/posctrl <ch> [kp ki kd [olim [ilim [period [ptype]]]]]` | 位置环 PID（0.1° 精度）。olim=输出限幅(RPM)；ilim=积分限幅(0.1° 单位)；其余同 speedctrl |
| `/mode` | `/mode <ch> [open\|speed\|pos]` | 控制模式：open=开环(PWM)，speed=速度闭环(RPM)，pos=位置闭环(0.1°) |
| `/cpr` | `/cpr <ch> [val]` | 编码器线数（每转物理刻度数），0 = 强制开环 |
| `/inv` | `/inv <ch> [0\|1]` | 电机方向反转（引脚级，交换 IN1/IN2） |
| `/einv` | `/einv <ch> [0\|1]` | 编码器信号极性反转（软件取反，统一顺时针为正） |
| `/posangle` | `/posangle <ch> [val]` | 位置环转一圈脉冲数（物理线数，固件自动 ×4），0 = 使用编码器 CPR |

### 2.4 编码器/滤波指令（2 条）

| 指令 | 语法 | 说明 |
|------|------|------|
| `/enczero` | `/enczero <ch>` | 清零指定通道编码器累计计数（同时重置 PID 和位置环） |
| `/filter` | `/filter <ch> [type] [window]` | 速度滤波器：type 0=无 1=滑动平均 2=一阶低通 3=中值；window：MA/中值 1~32，LPF 1~99 |

### 2.5 UART2 通讯指令（3 条）

| 指令 | 语法 | 说明 |
|------|------|------|
| `/uart2` | `/uart2 [baud] [inv] [mode]` | USART2 配置。baud=1200~4000000；inv=0 正常/1 反相；mode=`uart`/`sbus`/`elrs`（elrs 自动置波特率 420000） |
| `/priority` | `/priority [0\|1]` | 控制优先级：0=USART2 优先（默认），1=USB 优先 |
| `/timeout` | `/timeout [ms]` | 指令超时保护（0=关闭）；同时作为优先级心跳窗口（最小 100ms） |

### 2.6 遥控参数指令（6 条，SBUS / ELRS 共用）

| 指令 | 语法 | 说明 |
|------|------|------|
| `/smap` | `/smap <ch> [sbus_ch]` | 遥控通道映射（ch=1~4 → 遥控通道 1~16，每电机必须绑定） |
| `/rmap` | `/rmap <ch> [0\|1]` | 映射模式：0=中心零点（双向，默认），1=min 零点（单向） |
| `/dmap` | `/dmap <ch> [enable] [dir_ch]` | 方向映射：方向通道中心→停，上边界→正转，下边界→反转 |
| `/dinv` | `/dinv <ch> [0\|1]` | 遥控默认反转：通道级静态方向反转，上电即生效，不依赖遥控器开关；与 `/dmap` 乘法叠加。电机模式 ch=1~4 对应 A~D，底盘模式 ch 1~3 对应 vx/vy/ω（ch4 保留） |
| `/sbusparam` | `/sbusparam <ch> [val]` | 摇杆满偏对应目标值：开环=最大 PWM，速度=最大 RPM，位置=最大角度(0.1° 单位) |
| `/sbusrange` | `/sbusrange [min] [max]` | 通道值范围上下界（合法域 100 ≤ min < max ≤ 2047） |

### 2.7 底盘指令（1 条）

| 指令 | 语法 | 说明 |
|------|------|------|
| `/chassis` | `/chassis [sub [args...]]` | 底盘构型与参数。无参=查询全部；带子命令=设置（RAM only，需 `/save` 持久化）；`type` 切换会复位 PID 状态但不改写各通道控制模式 |

`/chassis` 子命令：

| 子命令 | 参数 | 说明 |
|--------|------|------|
| `type` | 0~6 | 构型：0=禁用（单电机模式） 1=差速2WD 2=差速4WD 3=麦轮O 4=全向3WD 5=全向4WD-X 6=全向4WD-十字 |
| `wheel` | 1~65535 | 轮径（mm） |
| `geo` | `<0-2> <v>` | 几何（mm / 0.1°）：差速=轮距/轴距，麦轮=轴距/轮距，全向=半径/基准角 θ0 |
| `max` | `<0-2> <v>` | 限幅（vx/vy: mm/s，ω: 0.001 rad/s）——遥控满偏/指令限幅/斜坡上限一份值三用 |
| `accel` | `<0-2> <v>` | 加速度（vx/vy: mm/s²，ω: 0.001 rad/s²，分轴独立） |
| `stall` | 0~60000 | 失速判定时长 ms（0=禁用失速协调） |
| `stop` | — | 整车停止（斜坡归零） |

### 2.8 错误处理

- 无效命令返回 `Unknown command '/xxx'`。
- 通道号超出 1~4 返回 `ERR: ch 1-4`。
- 模式参数错误返回 `ERR: open/speed/pos`。

## 3. 二进制帧协议

用于实时控制与高效通信（ROS / 上位机程序交互）。所有多字节字段为**小端序（LE）**。

### 3.1 帧格式

```
┌──────┬──────┬──────┬───────────┬──────┐
│ SYNC │ CMD  │ LEN  │  DATA     │ CRC8 │
│ 0xAA │ 1B   │ 1B   │ 0~248 B   │ 1B   │
└──────┴──────┴──────┴───────────┴──────┘
```

- **SYNC:** 固定 `0xAA`
- **CMD:** 命令字
- **LEN:** DATA 段字节数（最大 248，config_t = 248）
- **CRC8:** 多项式 `0x07`，初值 0，计算范围 **CMD + LEN + DATA**（不含 SYNC）

**CRC8 参考实现（C 风格，各语言等价移植）：**

```c
uint8_t crc8(const uint8_t *d, uint16_t len) {
    uint8_t c = 0;
    for (uint16_t i = 0; i < len; i++) {
        c ^= d[i];
        for (uint8_t b = 0; b < 8; b++)
            c = (c & 0x80) ? (uint8_t)((c << 1) ^ 0x07) : (uint8_t)(c << 1);
    }
    return c;
}
```

**组帧：** `frame = [0xAA, cmd, len, data..., crc8([cmd, len, data...])]`

### 3.2 ACK 帧格式

```
成功: 0xAA + CMD + 0x01 + 0x00 + CRC8
失败: 0xAA + CMD + 0x01 + 0xFF + CRC8
受保护: 0xAA + CMD + 0x01 + 0x02 + CRC8（仅 WRITE_FIELD，目标偏移落入受保护区域）
```

- `err=0x00` 成功；`err=0xFF` 失败（LEN 不匹配、字段越界等通用错误）；`err=0x02` 受保护字段拒绝（仅 WRITE_FIELD：目标偏移 < 11，见 §5）。

### 3.3 命令一览（19 条）

| CMD | 名称 | DATA（发送） | DATA（应答） | 说明 |
|:---:|------|------------|------------|------|
| `0x01` | PING | 无 | ACK | 连通性测试 |
| `0x10` | READ_PARAM | 无 | config_t (248B) | 读取全部配置 |
| `0x11` | WRITE_PARAM | config_t (248B) | ACK | 写入全部配置（仅 RAM，受保护字段自动还原） |
| `0x12` | WRITE_FIELD | `[field_id:2B LE][value:nB]` | ACK | 按偏移量写入单个字段（目标偏移 < 11 拒绝，返回 0x02，见 §5） |
| `0x20` | SAVE_EEPROM | 无 | ACK | RAM 配置写入 EEPROM（约 190ms） |
| `0x21` | LOAD_EEPROM | 无 | ACK | 从 EEPROM 加载到 RAM |
| `0x22` | FACTORY_RESET | 无 | ACK | 恢复出厂默认（RAM+EEPROM） |
| `0x30` | MOTOR_RAW | `[ch:1B][dir:1B][pwm:2B LE]` | 无 | 单通道 PWM 直驱（旁路 PID）。ch=0~3；dir=0 正转/1 反转（内部取负）；pwm=0~1000。受优先级仲裁 |
| `0x31` | MOTOR_CTRL | `[m1~m4:4×4B LE]` | 无 | 四通道批量控制（核心控制帧，int32）。受优先级仲裁 |
| `0x32` | MOTOR_JOG | `[ch:1B 0~3][rpm:2B LE 有符号]` | 无 | 单轮点动（仅底盘模式生效）：覆盖该物理通道轮目标低速转动验向；rpm=0 清除；400ms 无刷新自动解除 |
| `0x40` | SUBSCRIBE | `[interval_ms:2B LE]` | ACK | 开启状态周期上报（最低 20ms） |
| `0x41` | UNSUBSCRIBE | 无 | ACK | 关闭状态上报 |
| `0x43` | DEBUG_SBUS | `[enable:1B]` | ACK | SBUS 16 通道实时上报开关 |
| `0x44` | DEBUG_SPEED | `[enable:1B]` | ACK | 速度原始值上报开关（STATUS_REPORT 帧扩展） |
| `0x52` | ENTER_BL | 无 | ACK | 软复位进入 Bootloader（写 RTC magic + SystemReset，OTA 一键下载用） |
| `0x53` | REBOOT | 无 | ACK | 系统重启（ACK 后延迟 100ms） |
| `0xF0` | STATUS_REPORT | 无（MCU 主动推送） | 见 §4 | 周期状态上报（需先 SUBSCRIBE） |
| `0xF1` | DETECT_REPORT | 无（MCU 主动推送） | `[proto:1B][inv:1B][baud:4B LE]` | 协议检测结果上报；proto=0 识别失败（inv/baud 无效），1=SBUS，2=UART，3=ELRS |
| `0xF2` | SBUS_DATA | 无（MCU 主动推送） | `[ch0~15:16×2B LE]` | SBUS 16 通道原始值（需 DEBUG_SBUS 开启） |

**MOTOR_CTRL（0x31）说明：** `m1~m4` 为四通道目标值（int32 LE），含义取决于各通道控制模式：开环 = PWM（±1000），速度 = RPM，位置 = 0.1°（±3600 = ±360.0°）。实时控制以 30/50/100ms 间隔**连续发送**该帧。

### 3.4 控制仲裁细节

- 0x30 / 0x31 帧只有在 `controller_can_control(feed_src)` 通过时才生效（见 §1 优先级说明）。
- 协议自动识别（`/detect` 或 FUN 键）期间控制帧被拒绝，电机保持停转保护。

## 4. STATUS_REPORT 帧格式（0xF0）

需先通过 `SUBSCRIBE`（0x40）开启，以设定间隔周期推送。

**常规模式**（DEBUG_SPEED=0，56B payload）：

```
[enc1~4:4×4B LE] [tgt1~4:4×float LE] [rpm1~4:4×4B LE] [sbus_frame_cnt:4B LE] [sbus_ok_cnt:4B LE]
```

| 字段 | 类型 | 说明 |
|------|------|------|
| enc[4] | int32 | 编码器累计脉冲数 |
| tgt[4] | float | 当前目标值（PWM/RPM/位置） |
| rpm[4] | int32 | 滤波后实时转速（RPM） |
| sbus_frame_cnt | uint32 | SBUS 帧组装计数 |
| sbus_ok_cnt | uint32 | SBUS 帧校验通过计数 |

**扩展模式**（DEBUG_SPEED=1，72B payload）：

```
[enc:16B] [tgt:16B] [rpm:16B] [rpm_raw:16B] [sbus_frame_cnt:4B] [sbus_ok_cnt:4B]
```

- `rpm_raw[4]`: int32，滤波前原始 RPM（追加在 rpm 之后）。

|------|:--:|:--:|------|------|

| cmd_timeout_ms | 15 | 2B | u16 | 超时保护（ms） |
| comm_flags | 17 | 1B | u8 | bit0-3=protocol(1=SBUS 2=UART 3=ELRS)，bit4=sbus_inv，bit5=ctrl_priority |
| control_mode | 18 | 1B | u8 | 每电机 2bit：0=开环 1=速度 2=位置 |

## 6. Bootloader 协议（OTA 刷写，进阶）

指令头 = `0xA5`，**无 CRC**。

```
BL 帧: [SYNC=0xA5] [CMD] [LEN] [data...]
```

| CMD | 值 | 说明 |
|-----|-----|------|
| CMD_READ | 0x10 | 读 EEPROM 版本（应答 6B：`[0xA5][0x10][0x03][hwA][hwB][hwC]`） |
| CMD_ERASE | 0x50 | 擦除 App 区（超时 20s） |
| CMD_WRITE | 0x51 | 写 Flash（`[addr:4B LE][data...]`，每块 128B，起始地址 0x08004000，超时 500ms/块） |
| CMD_VERIFY | 0x52 | 校验（`[size:3B LE][crc32:4B LE]`，超时 5s） |
| CMD_REBOOT | 0x53 | 重启进 App |
| CMD_BL_REQ | 0x55 | 握手帧 `[0xA5,0x55,0]` — 设备上电后 200ms 窗口内收到即停留 BL |
| ACK | 0x5A | 应答帧头：`[0xA5][0x5A][0x01][err]`，err=0x00 成功 / 0xFF 失败 |

**进入 Bootloader 的三种方式：** ① 运行中发 `0x52 ENTER_BL`（RTC magic + 软复位，一键下载主路径）；② 按住 FUN 键上电；③ 上电 200ms 内发 `[0xA5,0x55,0]` 握手。进入成功输出文本标记 `BL:BOOT`。

## 7. 常见问题

| 现象 | 原因 / 处理 |
|------|------------|
| USB 连不上 | 确认 CH340 驱动已装、波特率 **2000000-8N1** |
| 发控制帧电机不动 | 检查 `/priority`：USB 实时控制需先 `/priority 1`；检查 `/timeout` 未超时归零 |
| 控制帧时灵时不灵 | 协议识别（/detect）期间控制帧被拒绝，等待识别完成 |
| 文本指令无响应 | 检查是否带 `\n`（部分终端需 `\r\n`） |
| 版本不匹配 | 固件 SW_MAJOR 必须与上位机协议版本 D 一致 |
| 单片机/MicroPython 板连不上 RC 口 | 确认已 `/uart2 <baud> 0 uart` 且共地 |
| CRC 校验失败 | 确认 CRC8 计算范围是 CMD+LEN+DATA（不含 SYNC），多项式 0x07 初值 0 |
